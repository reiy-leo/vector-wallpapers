### 调研到的关键技术事实（避免重复踩坑）
1. **Cloudflare Workers 脚本上限已是 64 MiB**（旧文档的 1MB 已过时），静态资产 20000 文件（非 20），需 wrangler ≥4.34.0。URL 上限 16KB。
2. **iOS Safari 对 SVG `foreignObject` 判定不安全** → canvas 污染 → `toDataURL`/`toBlob` 抛 SecurityError。已验证无效的绕过手段：crossOrigin=anonymous、html2canvas allowTaint、toBlob 替代 toDataURL、WASM 读像素。可靠解：完全不用 foreignObject + 降级下载 SVG。
3. **导出的 SVG 不能残留 `var(--x)` / `currentColor`** —— 脱离页面上下文会解析成黑色。这条推翻了 PRD 原表述，架构中已裁决为「生成层输出字面量hex，CSS 变量仅用于 UI 层」。
4. Tailwind v4 不需要 postcss/autoprefixer（v4 内置前缀处理），多余的 PostCSS 链反而是升级坑。
