# 142 风格清单 × 现有 19 母题：可添加性判定

> 日期：2026-10-12
> 性质：**决策依据文档**，不修改任何产品事实。
> 关联：`docs/PATTERN-SELECTION.md`（上一轮取舍）、`docs/PRD.md`（产品事实来源）。
> 本文全部结论按 `docs/PATTERN-SELECTION.md` §4 的纪律得出：
> **可拆解性用量化指标判定，风格是否好看的部分才用目视，不靠印象。**

---

## 摘要（一页读完）

1. 清单实为 **143 条 / 142 个唯一风格**（「太阳朋克」重复一次），比标题的 100 条多 42%。
2. 判据沿用上轮唯一一条：**能否拆成 ≥3 个可独立设色的区域**。
   但必须先过一道**更前置**的筛子：**能否用纯矢量几何表达**——
   因为产品是 SVG 引擎，`docs/ARCHITECTURE.md` 的铁律已经排除了
   `<text>`、`<foreignObject>`、位图。
3. **摄影 12 类 + 绘画媒介 8 类 + 依赖文字的（阿拉伯书法）= 21 类直接出局**，
   占清单 15%。它们定义在笔触、光影、纸纹上，SVG 几何无对应物。
4. **真正的结构性缺口只有 6 个**，不是「还能加很多」：
   - B-repeat 缺 **星形铺砌 / 递变网点 / 镶嵌碎片** 三类重复逻辑
   - A-lines 缺 **涡卷有机曲线**
   - D-pixel 缺 **通道错位 / 等距体素**
5. 网络审美 14 类（赛博朋克 / 蒸汽波 / 梦核 / 哥布林核…）**全部 ≈ 现有母题 + 一套配色**。
   它们是**风格化上色方案**，不是新结构 → **应做成 preset，不应做成母题**。
   这是本清单里 ROI 最高的一类增量：**零渲染成本、零体积增长**。

## 第一部分：筛选管线（三道闸门，顺序不可颠倒）

上轮只用了一道判据（可拆解性），这轮必须补上前置闸门——
否则会把「水彩」「宝丽来」这类高对比、看起来很可拆的风格误判为入选。

```
候选风格
  │
  ├─ 闸门 1：矢量可表达？ ──── 否 ──→ 出局（21 类）
  │    · 依赖文字        → <text> 被铁律 4禁止
  │    · 依赖位图/光影   → 我们是矢量引擎，无对应物
  │    · 依赖笔触/纸纹   → SVG 无笔触概念
  │
  ├─ 闸门 2：可拆成 ≥3 个可独立设色区域？ ──── 否 ──→ 出局
  │    · 纯色元件改色 = 换肤
  │    · 渐变元件改色 = 只染一端，价值不在一个量级
  │
  └─ 闸门 3：与现有 19 个母题无结构重叠？ ──── 是 ──→ 重叠，降级为 preset
```

**闸门顺序的理由**：闸门 1 必须最先执行。「点彩派」的圆点明显可拆、
「宝丽来」的边框也明显可拆——如果先跑可拆解性，这两类都会通过，
然后我们浪费精力去论证为什么它们仍然做不了。

## 第二部分：闸门 1 —— 矢量可表达性（21 类出局）

### 2.1 出局清单

| 类目 | 风格 | 出局原因 |
|---|---|---|
| 伊斯兰艺术 | **阿拉伯书法** | 依赖文字 → `<text>` 铁律 4 禁止（字体依赖破坏导出纯净度） |
| 摄影（12 类） | 写实 / 胶片 / 黑白 / 纪实 / 街头 / 静物 / 产品 / 时尚 / 电影感 / 复古胶片 / 宝丽来 / 玩具相机 | 定义在**光学与光影**上，本质是位图采样。我们没有渲染器 |
| 绘画媒介（8 类） | 水彩 / 油画 / 丙烯 / 水粉 / 石墨素描 / 钢笔线稿 / 厚涂 / 薄涂 | 定义在**笔触与纸纹**上。SVG 是几何描述语言，无笔触概念 |
| 3D 艺术 | 写实 3D / 风格化写实 / 金属材质 / 玻璃材质 | 需要**光照与材质求解**，属渲染器职责 |
| 插画 | 写实插画 / 超写实插画 / 儿童绘本 | 具象形体感，矢量成本极高且不可控 |

**合计 21 类，占 143 条的 15%。**

### 2.2 一个必须点破的区分

「宝丽来风」看起来是强候选——有边框、有色偏、有方形画幅，
**视觉上非常可拆**。但它的可拆性来自「**后期处理的产物**」
（白边 + 褪色 + 颗粒），而这些产物需要像素级运算。

> **可拆 ≠ 可做。**
> 可拆解性只回答「用户能不能分开改色」，
> 不回答「我们能不能用几何把它画出来」。
> 这是上轮判据缺失的一环，本轮补上。

## 第三部分：闸门 2 —— 可拆解性（21 类出局）

通过闸门 1 后，再按「≥3 个可独立设色区域」筛。

### 3.1 出局清单

| 类目 | 风格 | 卡在哪 |
|---|---|---|
| 中国艺术 | 工笔 / 写意 / 水墨山水 / 青绿山水 / 文人画 | 核心是**墨色浓淡的连续调**，而非区域划分 |
| 日本艺术 | 浮世绘 / 大和绘 / 水墨禅画 / 琳派 / 侘寂 | 依赖**具象题材 + 材质质感**（纸、墨、木） |
| 韩国艺术 | 韩国民画 | 同上，具象 |
| 南亚艺术 | 波斯细密画 / 莫卧儿 / 拉贾斯坦 / 马杜巴尼 | **极精细具象花卉**，矢量成本不可控 |
| 现代艺术 | 印象 / 后印象 / 野兽 / 表现 / 未来 / 达达 / 超现实 / 抽象表现 / 新表现 / 大地 / 装置 / 观念 | 定义在**观念与笔触**，非几何 |
| 平面设计 | 后现代设计 / 反设计 / 拟物化设计 | 非视觉规则，或依赖光影 |
| 插画 | 植物学 / 概念 / 装饰性 / 拼贴 / 涂鸦 / 彩铅 / 粉彩 / 炭笔 | 具象或笔触 |

**合计 21 类。**

### 3.2 闸门 1+2 累计

**142 个唯一风格中，109 个（77%）在两道闸门下出局。**

这是合理的——本产品是**矢量几何壁纸生成器**，
不是画风模拟器。清单里绝大多数条目定义在**表现手法**（笔触、光影、材质），
而产品只能提供**几何结构**。

## 第四部分：闸门 3 —— 与现有 19 母题的重叠判定

### 4.1 现有 19 母题的结构覆盖图

| 分类 | 母题 | 核心几何机制 |
|---|---|---|
| A-lines | flow-lines | 等距流动曲线场 |
| | offset-grid | 错位网格 + 位移 |
| | arc-composition | 弧线构成 |
| | contour-rings | 同心等高环 |
| | bauhaus-blocks | 几何块面 |
| B-repeat | polka-dots | 规则点阵 |
| | hex-grid | 六边镶嵌 |
| | diamond-lattice | 菱形错位 |
| | triangle-tiling | 三角铺排 |
| | checker-mesh | 棋盘交替 |
| C-organic | dusk-ridges | 层叠山脊 |
| | liquid-mesh | 径向渐变团叠加 |
| | cloud-bands | 横向云带 |
| | aurora-wave | 褶皱光幕 |
| | blob-field | 有机斑点场 |
| D-pixel | memphis-grid | 孟菲斯构件散落 |
| | neon-pixels | 像素块 + 霓虹描边 |
| | new-wave-sunset | 扫描线 + 圆盘 |
| | pixel-terrain | 2D 像素高度场 |

### 4.2 结构性缺口（这才是真正的增量空间）

逐格检查重复逻辑后，发现 **6 个真缺口**：

| 缺口 | 所属分类 | 现有母题为何覆盖不到 |
|---|---|---|
| **星形铺砌**（girih） | B | 现有 B 类全是「单一基元平铺」（点/六边/菱形/三角/棋盘）。**没有多基元嵌套镶嵌** |
| **递变网点**（halftone） | B | `polka-dots` 是**等半径**点阵，无半径/密度的连续变化 |
| **镶嵌碎片**（mosaic） | B | 无不规则形状的碎片拼接 |
| **涡卷有机曲线** | A | `contour-rings` 是**闭合同心圆**，`flow-lines` 是**开放平行流线**。卷草涡卷是**自相似递归的卷曲曲线**，两者都不是 |
| **通道错位**（glitch） | D | `neon-pixels` 是正常像素，`new-wave-sunset` 是扫描线。**RGB 通道空间错位**无人做 |
| **等距体素** | D | `pixel-terrain` 是**2D 像素高度场**（正视），等距体素是**30° 斜投影立方体**（轴测），投影机制完全不同 |

### 4.3 重叠 → 降级为 preset（不新增母题）

| 风格 | 重叠对象 | 判定 |
|---|---|---|
| 包豪斯 | `bauhaus-blocks` | **高度重叠**，仅配色差异 |
| 孟菲斯 | `memphis-grid` | **同一母题的不同叫法** |
| 极简主义 / 极简设计 | A 类整体 | 已覆盖 |
| 瑞士国际主义 | `offset-grid` + `flow-lines` | 网格系统已覆盖 |
| 波普艺术 | `polka-dots` + 粗描边 | Ben-Day 点已有 |
| 色域绘画 | C 类渐变族 | 已覆盖 |
| 哥特式 / 新古典主义 | A 类线条族 | 装饰构件可归入 `bauhaus-blocks` 变体 |
| 体素艺术 / 等距视角 | 见 4.2 缺口 | 归入「等距体素」单一母题 |

## 第六部分：ROI 最高的路径 —— 14 个 preset，零新增母题

### 6.1 网络审美类目全部降级为 preset

清单里 14 个网络审美风格（赛博朋克 / 蒸汽波 / 合成波 / 千禧风 /
清新科技风 / 海洋朋克 / 故障核 / 梦核 / 怪核 / 阈限空间 / 暗黑学院 /
明亮学院 / 田园核 / 哥布林核 / 精灵核），拆开看**全部是
「现有母题 + 一套特定配色 + 一点后期感」**：

| 风格 | 最接近的母题 | preset 差异 |
|---|---|---|
| 赛博朋克 | `neon-pixels` | 青/品红高饱和 + 深蓝底 |
| 蒸汽波 | `new-wave-sunset` | 粉紫渐变 + 网格线 |
| 合成波 / 千禧风 | `new-wave-sunset` | 撞色 + Windows 95 灰绿 |
| 梦核 / 怪核 /阈限空间 | `cloud-bands` | 低饱和高明度 + 噪点感 |
| 暗黑学院 / 明亮学院 | `flow-lines` | 学院色（深棕金 / 象牙蓝） |
| 海洋朋克 / 清新科技风 | `liquid-mesh` | 青蓝 / 薄荷白 |
| 哥布林核 / 精灵核 / 田园核 | `blob-field` | 苔绿 / 叶绿 / 麦黄 |

### 6.2 为什么这比新增母题更值

| 维度 | 新增母题 | 新增 preset |
|---|---|---|
| 首屏体积 | +0.8~1.5 KB/个 | **0** |
| 渲染代码 | 新增 pattern + 测试 | 仅色值表 |
| 用户感知变化 | 图样变新 | 同一图样换肤，**正是产品的核心能力** |
| 违背铁律风险 | 需重跑体积/节点/纯色占比门禁 | 无 |

### 6.3 但要守住两条约束

1. **preset 不能替代母题**。PRD Q7锁的是「6–8 套固定合集」，
   那是**跨母题的策展合集**，与这里的**单母题配色预设**不是同一层东西，
   不要混为一谈。
2. **每个母题的 preset 上限建议 4 个**。现有全部母题都是 3 个 preset。
   无限扩张会让「随机配色」这个功能失去意义——
   预设的意义是**提供高质量起点**，不是穷举。

## 第八部分：本文的局限（诚实披露）

1. **未做量化指标实测**。上轮判读（参考站 48 张）是用
   **亮度标准差 SD** 量化后交叉验证的。本文对 142 个风格是
   **按定义归类**，因为清单里大部分条目（如「侘寂」）**没有对应的参考图**，
   无从计算 SD。
   → 若要用于生产决策，需对 Tier S 的 4 个候选取参考图补做量化复核。

2. **「纯色元件预案」是设计意图，不是实测值**。
   标为 4/4 的是**按机制推断**（例如剪纸天然全是纯色），
   实现后仍须由 `structure.guard.test.ts` 实测确认。

3. **未验证视觉质量**。本文只回答「能不能做」，
   完全没回答「好不好看」——后者需要出图后目视，
   而目视结论必须落在 `previews/` 里的实际产物上，不能凭描述判断。
